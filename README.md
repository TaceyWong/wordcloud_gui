# WordCloud-Gui 增强版
词云生成工具 - 桌面GUI软件

## 项目简介

WordCloud-Gui 是一个基于 wxPython 的词云生成桌面应用程序。本增强版在保留原有功能的基础上，扩展了数据处理、可视化、导出与兼容性能力，大幅提升了用户体验与实用性。

## 主要功能

### ✨ 新增功能

**数据输入扩展**
- 📂 多数据源导入：支持 TXT/CSV/Excel（XLS/XLSX）文件导入
- 🧹 文本清洗：自动去除停用词、标点符号、数字、特殊字符，可自定义停用词表
- 📝 分词自定义：支持中英文分词，可添加自定义词典（jieba 分词）

**词云生成增强**
- 🎨 丰富样式配置：自定义字体、背景色、蒙版图片（心形/圆形/自定义轮廓）、颜色方案（30+种配色方案）
- 📊 词频统计可视化：自动生成词频TOP20柱状图，展示高频词分布
- 👁️ 实时预览：调整参数后可实时预览词云效果

**导出与分享优化**
- 💾 多格式导出：支持导出为 PNG/JPG/PDF/SVG 格式，可自定义分辨率（高清导出）
- 📄 报告生成：自动生成词云分析报告（含词频统计、词云图、高频词列表），导出为 PDF/Markdown

**兼容性与体验提升**
- 🌍 跨平台兼容：支持 Windows/macOS/Linux 运行
- 🌓 界面现代化：重构 UI 布局，新增暗色/亮色主题切换，支持界面缩放
- 📦 批量处理：支持批量导入多个文本文件，批量生成词云并保存
- ❓ 帮助文档完善：补充详细使用教程、常见问题解答

## 技术栈

- **GUI 框架**: wxPython
- **词云生成**: wordcloud
- **数据处理**: pandas、jieba（分词）
- **可视化**: matplotlib
- **PDF 生成**: reportlab（可选）

## 安装与运行

### 环境要求

- Python 3.6+
- pip 包管理器

### 安装依赖

```bash
pip install wxpython wordcloud jieba pandas matplotlib pillow numpy openpyxl
```

如需 PDF 报告功能，还需安装：
```bash
pip install reportlab
```

### 运行程序

```bash
python Main.py
```

## 使用说明

### 快速开始

1. **数据导入**
   - 点击「导入文件」或「批量导入」选择数据文件（支持 TXT/CSV/Excel）
   - 可选择自定义停用词表和词典文件
   - 配置文本清洗选项（标点、数字、特殊字符）
   - 点击「开始处理文本」

2. **词云配置**
   - 设置词云尺寸、边距、缩放比例
   - 选择字体、字号范围
   - 配置背景色、颜色方案
   - 可选：选择蒙版图片实现自定义形状

3. **生成与预览**
   - 点击「生成词云」生成词云
   - 点击「实时预览」调整参数并即时查看效果
   - 点击「显示词频统计」查看词频分布图表

4. **导出**
   - 图片导出：支持 PNG/JPG/PDF/SVG 格式，可设置 DPI
   - 报告导出：生成 PDF/Markdown 格式的分析报告
   - 数据导出：导出词频统计数据为 CSV/Excel 格式
   - 批量处理：对多个文件批量生成词云

## 常见问题

### Q: 中文显示乱码怎么办？
A: 请在字体设置中选择支持中文的字体（如 `simsun` 宋体）。

### Q: 支持哪些文件格式？
A: 数据导入支持 TXT、CSV、Excel（XLS/XLSX）格式。图片导出支持 PNG、JPG、PDF、SVG 格式。

### Q: 如何自定义词云形状？
A: 在「词云配置」面板中点击「选择蒙版图片」，支持 PNG/JPG/BMP 格式的图片作为蒙版（建议使用白色背景、黑色轮廓的图片）。

### Q: 如何添加自定义词典？
A: 在「数据导入」面板点击「自定义词典」，选择 TXT 格式的词典文件（每行一个词）。

### Q: 如何进行批量处理？
A: 在「数据导入」面板选择「批量导入」，选择多个文件后，在「导出」面板点击「批量生成词云」。

### Q: 程序支持哪些操作系统？
A: 支持 Windows、macOS、Linux 三大操作系统。
